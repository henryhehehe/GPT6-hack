## Approachable Astra characters — September 10, 2026

Added three named scene characters with clickable geometry, projected name labels, and a keyboard/touch directory. The conversation modal supports free questions, follow-ups, persistent drafts, separate per-character/per-scenario history, source buttons, and a transition to the student's own argument. All dialogue is labeled simulated. New optional dialogue state is backward-compatible with existing student rows; no database migration was needed. Stored requests use stable IDs for retries, capped at 40 messages per learner/classroom. Model history uses the last six turns with that character in that scenario and never uses caller-provided student history.

The `talk` action authenticates the learner, validates the character/question/scenario, calls Astra with a bounded structured response, validates evidence IDs, and stores the result with its response ID and latency. It never changes inventory, rubric turns, or unlock status. Sources are summaries, not automatically trusted character testimony. Semantic grounding is prompted and sampled, not formally proven.

To preserve conversations during long requests, student writes now atomically check classroom version and student revision. World replacement atomically refuses existing evidence, arguments, or dialogue. Regression tests exercise both orders of world/progress writes in SQLite using the production SQL. Saved student credentials restore student mode; asynchronous refreshes accept only responses newer than the last applied response for the current classroom. Draft text typed during an earlier submission is preserved.
