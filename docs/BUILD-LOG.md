## Textbook-to-world authoring

Added a teacher intake → automatic preparation → evidence review → new classroom flow. Inputs: pasted text, TXT/Markdown, PDF upload (5 MB), or a direct public HTTPS PDF link. PDF reading range defaults to the first ten pages. Text inputs are limited to 60,000 characters and must contain the selected reading range. Astra extracts PDF excerpts with page locators, then composes a subject-aware lesson: three places, three conversational characters, local source cards, reading activities, central question, and conditional what-if. Teacher review is required before students receive the lesson.

Source handling uses a generated D1 migration for durable drafts and private R2 uploads. Text excerpts retain supplied wording; PDF extraction is explicitly model-derived and requires comparison against the original. The model chooses from canonical passage IDs; server code fills source text/citations rather than allowing generated quotations. Every place must have local linked evidence. New-class launch uses fixed draft-specific credentials and atomic insert-or-ignore statements, so retry returns the same classroom and never overwrites an existing one. Original uploads remain accessible to the source teacher and the authenticated teacher of the launched classroom; unrelated teachers and learners are denied.

Imported material uses reusable coast/garden/archive learning settings with walking, evidence stations, character interaction, and activity prompts. These are symbolic settings, not arbitrary high-fidelity reconstructions of a textbook. Literature assessment uses textual analysis and alternative readings while retaining the existing evidence-gated scoring contract. The prepared Alexandria scene remains available separately.

Independent code review found five issues (stale PDF preview, missing link provenance, source access after launch, empty evidence stations, stale builder restoration); all were fixed and the reviewer found no remaining P0/P1 issues in the incremental review. A live generation attempt tried to rename source IDs and was rejected; constraining IDs in the model output schema now prevents that failure. A later PDF lesson-generation request exceeded 65 seconds; generation now emits only evidence references instead of repeating excerpts and builder-specific model calls allow 120 seconds, preserving the draft for retry.

Validation completed: 33 automated tests, TypeScript check, existing classroom smoke, and production build passed. Live text generation (39.2 s) verified literary subject selection, exact source grounding, teacher review gate, idempotent launch, preserved prior classroom, and a context-aware character reply (3.8 s). Real one-page PDF extraction matched the original test story and page 1, and rejected learner source access. Resuming the saved PDF draft generated its lesson in 31.8 s and verified original-file access with the launched teacher's credentials. The intake form and generated walking scene were visually inspected in the app preview. Direct public-PDF URLs follow the documented Responses file-input path but were not separately live-tested. Text extraction prefers paragraph/sentence boundaries and preserves source locators. Native book-specific architecture, whole-book exhaustive coverage, and automatic verification of PDF extraction remain outside this release.
