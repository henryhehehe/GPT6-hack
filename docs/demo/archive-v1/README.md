# One-minute hackathon demo

Working demo package for Counterfactual Worlds. Maintained every 30 minutes by the **Keep hackathon demo current** task follow-up. Start with [the timed script](SCRIPT.md), then [the recording guide](RECORDING.md). [Status](STATUS.md) records what was actually exercised and what needs another take.

The deliverable is a 60-second narrated **screenshot walkthrough draft** of the real published app. It uses an isolated prepared Alexandria classroom and the teacher's own student-preview identity. It is not continuous screen footage, a generated-from-upload lesson, or a multi-student acceptance test. The final recording plan preserves the same teacher → student → teacher challenge → student revision story.

Files:

- `output/demo/counterfactual-worlds-60s-draft.mp4`: narrated draft, real app screenshots, burned-in captions.
- `output/demo/voiceover.wav`: synthetic scratch narration; replace with the builder's voice if preferred.
- `docs/demo/voiceover.txt`: clean narration for a microphone take.
- `docs/demo/captions.srt`: timed captions, also embedded in the draft.
- `docs/demo/timeline.json`: edit timing and exact narration for each shot.
- `output/demo/captures/`: original browser captures; preserve for comparison as the app changes.
- `scripts/demo/render.py`: reproducible draft renderer.

Opening premise: **What if a history lesson became a place you could investigate?** Closing payoff: the student replaces an overconfident answer with an evidence-based, conditional explanation. Keep both interfaces. The changing harbor draws attention; the reasoning loop explains why the product matters.

Keep the source importer as an alternate opening after a complete imported lesson has been rehearsed. Do not cut from source upload to prepared Alexandria in a way that suggests the upload generated that exact scene. New book-specific worlds, selected-learner fixes, and formal before/after comparison belong in the film only after verification.
