# Live museum demo

Entry: `/collections` → **Try the museum demo**, or directly `/try?museum=1`.

1. **Object, about 20 seconds.** The coin photograph opens immediately. Zoom to 150–200%, then scroll across the two sides. Point out the museum’s name, accession number, date and CC0 label. Say: “We begin with a real object. What can we observe, and what are we interpreting?” The coin is not generated artwork or a scanned 3D model.
2. **Source, about 20 seconds.** Choose **Read Strabo’s account**. Read the exact excerpt and its separately labeled context note. Say: “The coin presents royal imagery. This written account describes a scholarly institution. Neither establishes the exercise’s trade-funded budget.” Save the source to the journal if the presenter wants to demonstrate persistent evidence collection.
3. **Explanation, about 20 seconds.** Add the source citation using the reader’s existing button, or close it and choose **Build your explanation / Continue your explanation**. Write your own reasoning; no sample answer is silently inserted. Use the funding assumption and invented ledger only as labeled exercise material. If submitting a real demo answer, wait for and inspect the actual feedback rather than narrating an expected result.
4. **Teacher handoff, optional.** In a new practice classroom, switch to Teacher studio → Museum objects. Three Alexandria objects are already selected. Demonstrate changing a selection, then open the Teaching guide & worksheet. The download includes source citations and an optional observation / interpretation / limitation exercise. It adds no extra minutes to the existing planning estimate; run it within investigation time.

The route resumes existing practice work. An older trial can have learner-only access; its artifact tour still works, but use a new practice session to demonstrate teacher controls. Do not erase an existing learner’s work to make a recording. Museum magnification and navigation make no AI calls, collect no evidence automatically, and do not change the learner’s draft. Saved-object defaults apply to newly created practice classrooms only.

This is an interactive demo extension. The existing recorded films and their voiceovers remain unchanged.

## Optional comparison beat

After inspecting the gold coin, choose **Compare gold & silver coins**. Enlarge either photograph independently. Compare the recorded dates and materials as well as the imagery, then use the same **Read Strabo’s account** button to continue. Photographs are fitted separately; use the listed dimensions when discussing physical size. From the full collection, choose **Compare** on any two records and then **Compare objects**. This viewing selection does not add or remove objects from a lesson.
