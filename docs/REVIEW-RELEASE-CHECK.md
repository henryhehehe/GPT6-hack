# Check the reviewed learning flow before release

The shared checkout and release branch have evolved separately. A successful build can still combine an older classroom API with newer UI. Run this check against each candidate's actual built Worker to catch regressions in the original independent-review fixes.

From the candidate checkout, after its normal production build:

```sh
node --import tsx scripts/check-review-learning.mjs
```

The check starts a temporary local Worker with ephemeral D1/R2 storage, synthetic learners, and fake credentials. All outbound requests are intercepted. Five fixed responses exercise persistence and transport behavior; none are generated by a model or represent an evaluation of grading quality. The Worker is disposed on completion or failure.

It verifies:

- An initial prediction is required and saved; uncollected, forged, stale, and duplicate passages reject before upstream work.
- Missing/foreign learner selection and student attempts to direct reject over both HTTP and WebSocket.
- A valid HTTP director request uses learner B's stored work even when caller-supplied work is forged; the returned hint retains B's identity and its market location.
- Applying the same hint twice is idempotent. A lost-response argument retry returns its original saved feedback even after the hint changes the classroom version; changed content cannot reuse its ID.
- Revised text retains its selected passages, linked original, reflection, and hint; unchanged text does not become a completed revision. Teacher and learner reads preserve the correct ownership and history.
- Archive reflection persists, meaningful learner progress prevents regeneration, and omission of a reviewed historical source cannot replace a fresh classroom's world.

Validated September 10 against the production output for runtime commit `96ec33a`, based on release `252c375`. This check complements `check-pilot-reservation-order.mjs`. It does not exercise browser rendering, keyboard/reload usability, a valid native steering response, real model quality, or production hosting access. The final independent usability review remains outstanding.
