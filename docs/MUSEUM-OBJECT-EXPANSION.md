# Museum object expansion — 10 September 2026

The collection now contains **60 objects across all ten curriculum worlds**, from Cleveland Museum of Art and The Metropolitan Museum of Art. Fifty-three additions beyond the original seven retain object-specific CC0/public-domain image verification. The original seven records and three guided investigations remain intact; seven more investigations now cover the remaining topics.

## Use in the app

1. Open `/collections` and choose a lesson topic. Search by title, maker, accession, material, date, lesson topic, or discussion language; filter by museum when needed.
2. Use **Inspect & zoom** for the photograph, complete museum attribution, a discussion prompt, and the limits of the connection. Choose **Compare** on any two objects for side-by-side inspection.
3. In the classroom’s **Museum objects** dialog, the assigned curriculum selects the matching topic for all ten worlds. Add up to six objects; learners receive only the teacher’s selections.
4. Use a learner field note to separate an observation, an interpretation, and a remaining question. Selected objects retain citations and limits in the existing teacher and learner downloads.

Objects are optional contextual supplements. Adding a record does not attach it to existing classrooms or turn it into a scored source card. Museum photographs are remotely hosted; saved metadata and questions remain readable when an image is unavailable.

## Suggested comparisons

- **Alexandria:** compare the alabastron and Mit Rahina ware vessel. Distinguish material, decoration, and function from unproven claims about a particular trade route or library.
- **The Odyssey:** compare the silver drinking cup with the terracotta recognition plaque, separating hospitality as a question from the different episodes and dates.
- **Macbeth:** compare Lupton’s atmospheric interpretation with the satirical print of a country performance. Distinguish picturing the story from picturing how people perform it.
- **The Tempest:** compare Miranda’s single-figure print with the grouped scene after Mortimer; identify how each print directs sympathy and return to the speakers’ words.
- **Dickens:** compare the old clothes shop with the existing morning dress, using the later photograph as a question about reuse and judgment, not a photograph of a fictional scene.

- **Douglass:** compare the ca. 1855 daguerreotype with Warren’s 1876 photograph. Separate what each image shows from the literacy episode in the 1845 Narrative.
- **Seneca Falls:** compare Stauffer’s 1830 sampler and the ca. 1845 afternoon dress. Neither establishes a national educational or legal condition; return to a specific grievance and identify what further evidence it needs.
- **Declaration:** compare the 1823 retrospective etching with the c. 1780–95 desk. Both postdate 1776. Discuss the work and later representation of public argument without identifying the desk as a drafting site.
- **Frankenstein:** compare the later Prometheus print with Goya’s independent reading scene. These are analogies for discussion, not illustrations of Shelley’s fictional events.
- **Austen:** compare the existing British cotton dress with the 1810–12 evening dress. Keep the latter’s “American or European” attribution; a visual comparison cannot invent an owner or motive.

These remain optional comparison ideas. Ten registered guided investigations are now available as described in [the investigation guide](MUSEUM-INVESTIGATION-GUIDE.md). Each of the 53 added objects has its own original discussion prompt and explicit interpretive limits in `lib/museums/collection.json`.

## Provenance and maintenance

`assets/museums/source-records/` retains the exact API fields used to normalize each addition, its public API endpoint, and the retrieval date. Large biographies and unused fields are omitted; image URLs are retained without downloading photographs. The original Alexandria tour is now an explicit selection of its three original objects, so having seven Alexandria objects in the broader collection does not overflow the classroom limit.

The source-record fixtures make normalization, attribution, dates, and rights review reproducible offline.

- Cleveland records require `share_license_status: "CC0"` and the approved museum image host. The normalizer now retains creator qualifiers such as “attributed to.” Missing free-text measurements are labelled unavailable rather than inferred.
- Met records require `isPublicDomain: true` and an approved museum photograph URL. Uncertain culture, publication/reissue dates, and creator qualifiers remain intact. The Tempest entry identifies the engraver and explains the after-Fuseli/reissue relationship in its reading limits.
- `scripts/museums/review-refresh.ts` already iterates over the approved catalog, so it now reviews all 60 records. It writes a candidate to `/private/tmp/cw-museum-review.json`; review changes before replacing the catalog.
- To add another record, verify the museum metadata and rights, retain its normalization fields in a source snapshot, write a connection/prompt/limits, and append a unique ID. Add a topic mapping only when it corresponds to a supported curriculum identity. Keep the classroom limit at six.

Primary API documentation: [Cleveland Open Access API](https://openaccess-api.clevelandart.org/) and [The Met Collection API](https://metmuseum.github.io/).

## Reusable object and comparison links

Every inspector offers **Link to this object** and **Copy link**. Custom comparisons offer the equivalent link for the ordered pair, including pairs from different topics. The link contains only reviewed public object IDs. It does not include classroom IDs, access tokens, learner notes, or answers, and opening it does not save objects into a classroom.

Examples: [inspect the reticule](http://localhost:5173/collections?object=met-84629), [compare the reticule with a dress](http://localhost:5173/collections?object=met-84629&compare=met-90487). The app uses its current origin when copying, so a hosted page produces a hosted link. Existing `?study=` investigation links remain valid and take precedence. Unknown, repeated, incomplete, or duplicate selections fall back to the collection browser. Same-topic links filter the collection; mixed-topic pairs keep all topics available.

Closing the inspection leaves the link in the address bar; reloading it opens the selection again. If clipboard access is unavailable, the visible link remains usable.

Fourth expansion validation: all 37 museum tests, scoped museum TypeScript, and the Sites production build passed. All five added image URLs returned HTTP 200 to HEAD requests. Local single-object, custom-comparison, and invalid-selection routes returned HTTP 200; query parsing and fallback behavior are covered by the link tests. The build retains its large-chunk advisory. No browser visual review or deployment was performed; this checkpoint is ready for the coordinated release following v19.
