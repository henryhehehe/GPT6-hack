The current homepage uses `alexandria-library-current-1920.webp` and its responsive `alexandria-library-current-960.webp` variant. The screenshot includes the current charcoal/vermilion interface, detailed library architecture, textured scene assets, and current characters. It is a real browser capture, with no generated or retouched scene content.

The original capture was encoded to WebP at quality 94 without resizing; the 960×540 variant uses quality 92. The homepage preserves the full 16:9 frame and chooses the appropriate source for screen size and pixel density. The caption identifies it as a capture rather than a live feed.
