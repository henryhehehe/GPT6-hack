# One-minute teacher → student demo

This supersedes the three-minute stage script. Record the actual working interfaces; keep API waits as clearly visible cuts, never fake generated results. Teacher and student views must share the same classroom state. A second browser can join with the student link.

| Seconds | Interface | Shot and narration |
|---|---|---|
| 0–10 | Teacher | Lesson text, objective, and “What if harbor trade collapsed?” Generate/preview. “Turn a lesson into a world students can question.” |
| 10–23 | Student | Wide harbor shot. Toggle the hypothesis; ships, market, and library transform. “Change one cause. Explore what follows.” |
| 23–33 | Student | Open evidence, submit a weak claim, receive an actual Astra challenge. “Characters ask for evidence, not the expected answer.” |
| 33–45 | Teacher | See the student's missing reasoning, request a visual hint, preview/apply. If native steering works, add the simpler-language correction while it runs. |
| 45–56 | Student | Hint appears in the world. Submit an evidence-based revision. Archive opens. |
| 56–60 | Student → compact inspector | Show rubric result and actual model run. “Counterfactual Worlds. Teach the reasoning, not just the answer.” |

Priority: both interfaces, real world transformation, live model output, preserved state. Show the causal inspector and source labels briefly in-context. Development evidence and technical details belong in the submission README rather than occupying video time.

Record real generation ahead of editing the video. A prepared fixture must say “Prepared lesson”; a cached generated world must say “Generated earlier.” A one-minute edit may cut waiting, but must not imply a measured one-minute total workflow.
